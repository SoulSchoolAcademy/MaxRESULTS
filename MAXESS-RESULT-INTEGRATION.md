# MAXESS Results Integration Contract

## Authoritative flow

`AIScoreMAXESS` → `MAXESS_RESULT_V1` → `results.nayanet.app` → `MAXESS_RESULT_CONSUMER_V1` → `window.MAXESS_RESULT` → E01–E06

## Live deployment responsibility

Groove deployment is manual. This repository stores the source and integration contract. The bridge is copied manually into the Groove Results page at `results.nayanet.app`.

## Consumer

`MAXESS-RESULT-CONSUMER-V1.html`

The consumer reads the `#maxess-result=` hash, decodes URL-safe Base64 JSON, validates the `MAXESS_RESULT_V1` contract, publishes `window.MAXESS_RESULT`, and dispatches:

- `MAXESS_RESULT_READY`
- `maxess:result-updated`

No demo score or fallback result is generated by the consumer.

## Retired artifacts

Do not modify or reuse:

- `20260817 912am RESULTS PAGE CODE`
- the retired `.xyz` Results implementation

## Deployment

1. Copy the complete contents of `MAXESS-RESULT-CONSUMER-V1.html` into a standalone HTML/Code embed on the Results page.
2. Place it before E01–E06 so the consumer initializes early.
3. Publish the Groove page manually.
4. Run the assessment through all 15 questions.
5. Confirm the browser navigates to `results.nayanet.app/#maxess-result=...`.
6. Confirm E01–E06 receive the same `window.MAXESS_RESULT` object.
7. Test at least two materially different result payloads.
