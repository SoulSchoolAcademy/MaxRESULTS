# MAXESS Results Integration Contract

## Authoritative flow

`AISCORE.NAYANET.APP` → `MAXESS_RESULT_V1` → `results.nayanet.app` → `MAXESS-RESULT-CONSUMER-V2` → `window.MAXESS_RESULT` → E01–E06

## Live deployment responsibility

Groove deployment is manual. This repository stores the source and integration contract. The bridge must be copied manually into the Groove Results page at `results.nayanet.app`.

**Critical deployment rule:** GitHub source presence does not prove live Groove installation. The bridge is not considered LIVE VERIFIED until the published Results page contains the bridge and a real assessment payload hydrates E01–E04 in the browser.

## Consumer

`MAXESS-RESULT-CONSUMER-V2.html`

The V2 consumer:

- reads `#maxess-result=` from the current URL hash;
- decodes URL-safe Base64 JSON;
- validates the `MAXESS_RESULT_V1` contract;
- publishes the authoritative object as `window.MAXESS_RESULT`;
- persists the valid result in `sessionStorage`;
- dispatches `MAXESS_RESULT_READY` and `maxess:result-updated`;
- tolerates late-loaded Groove sections through bounded hydration polling;
- rehydrates on `hashchange` and `pageshow`;
- synchronizes E02's visible dimension labels from the authoritative result dimensions.

No demo score or fallback result is generated by the consumer.

## Dimension contract

The assessment's authoritative five dimensions are:

1. Direction
2. Context
3. Collaboration
4. Evaluation
5. Iteration

E02 must display those same five dimensions in the same order. Section-local labels must never redefine the scoring model.

## Deployment

1. Copy the complete contents of `MAXESS-RESULT-CONSUMER-V2.html` into ONE standalone HTML/Code embed on the Results page.
2. Place it before E01–E06 so the consumer initializes early.
3. Publish the Groove page manually.
4. Run the assessment through all 15 questions.
5. Confirm the browser navigates to `results.nayanet.app/#maxess-result=...`.
6. Confirm `window.MAXESS_RESULT` exists and contains `contractVersion === 'MAXESS_RESULT_V1'`.
7. Confirm E01 displays `overallScore` and E02 displays all five dimension scores under Direction, Context, Collaboration, Evaluation, Iteration.
8. Confirm E03 resolves the same `masteryBand` and E04 resolves the Direction score from the same object.
9. Test at least two materially different result payloads.
