Canonical system: [`docs/SMART-NOTES.md`](../SMART-NOTES.md)

This index is the first retrieval surface for durable project learning. Search by **date, Entry ID, type, scope, concept, keyword, or alias**. Keywords are intentionally redundant so an AI does not need to remember the exact phrase used in the original conversation.

## Retrieval rules

- Start here before opening daily note files.
- Search natural-language concepts, synonyms, aliases, and related vocabulary, not only exact titles.
- If a result looks relevant, open the linked daily note and read the full entry.
- Current repository authority always outranks historical memory.
- When a note is superseded, keep the old index row and point to the replacement.
- If the human says “Naya Note,” “Smart Note,” “Naya Notes,” “Smart Notes,” “make a note,” or “check the notes” in a project-memory context, route to this system.

## Maintenance law

Every new durable note gets:

1. a stable Entry ID;
2. an ISO-8601 timestamp with timezone;
3. broad keywords and aliases;
4. a one-sentence summary;
5. an evidence pointer;
6. an explicit action or implication;
7. an index row.

Do not create orphan notes that are absent from this index.
