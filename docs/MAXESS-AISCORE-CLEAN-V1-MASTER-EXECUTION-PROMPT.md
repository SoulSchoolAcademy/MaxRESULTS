# 13. SCORING ENGINE

Maximum raw score:

`15 × 4 = 60`

Overall:

`totalRawScore = sum(all 15 selected answer values)`

`overallScore = round((totalRawScore / 60) × 100)`

Dimension:

Each dimension has 3 questions.

`dimensionRawScore = sum(the three selected values)`

`dimensionScore = round((dimensionRawScore / 12) × 100)`

Do not invent missing responses.
Do not substitute defaults.
Do not display a fallback score.

If scoring fails:

**FAIL SAFELY.**

Never manufacture a result.
