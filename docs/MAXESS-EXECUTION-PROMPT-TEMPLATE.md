# 15. OSCAR — INDEPENDENT CRITIC

Oscar must try to disprove success.

Ask:

- Does every word make sense?
- Is anything confusing, redundant, generic, technical, or unfinished?
- Is anything present that the user does not need?
- Is anything missing that the user needs?
- Does the hierarchy tell the story instantly?
- Is the score unquestionably the hero?
- Does the Orb remain intact?
- Does the page feel premium rather than decorated?
- Does mobile remain excellent?
- Is there any clipping, overlap, overflow, or awkward wrapping?
- Is any state text leaking implementation details?
- Does the real result flow correctly?
- Did anything protected regress?
- Would a first-time user understand what this means and what happens next?
- Would a skeptical expert call this AAA?

If any answer is materially negative: **REPAIR → RE-TEST → ATTACK AGAIN.**
