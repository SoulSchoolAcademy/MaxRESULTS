# MAXESS RESULTS — MASTER DESIGN DIRECTIVE V2

Status: PROPOSED AUTHORITATIVE MASTER DESIGN DIRECTIVE
Repository: `SoulSchoolAcademy/MaxRESULTS`
Branch: `maxess-results-v21-working`
Purpose: Define the exact psychological, visual, content, interaction, motion, data, conversion, responsive, accessibility, and implementation behavior required to turn MAXESS Results into an extraordinary Personal AI Mastery Report.

This directive is intentionally implementation-specific. It is not a mood board. It is not a list of adjectives. It is the design contract that tells an implementing AI what to build, why it exists, how it should look, how it should behave, what must be preserved, and what evidence proves it is successful.

It extends and operationalizes:

- `docs/MAXESS-MASTER-CONTRACT.md`
- `docs/MAXESS-AAA-SECTION-DESIGN-SPEC.md`
- `docs/AI-DEFINITION-OF-10.md`
- `docs/AI-PRODUCT-LANGUAGE.md`
- `docs/NAYA-LEAD-MODE.md`
- `docs/NAYA-SELF-DIRECTED-BOOTSTRAP.md`
- `docs/HMC-MAXIMUS-BUTTON-AND-ICON-SYSTEM.md`
- `docs/MAXESS-HMC-REFERENCE-PACK.md`
- current authoritative Results artifact and current V21 renderer architecture

The current live baseline contains a score, five dimensions, fingerprint, interpretation, pathways, growth actions, playground, personalized report, Naya, video, and continuation links. The purpose of V2 is to transform those ingredients into a single coherent experience rather than simply adding more content.

# 03 — PSYCHOLOGICAL CHOREOGRAPHY

MAXESS uses three simultaneous psychological layers.

## TRUST

The user must feel safe before they feel impressed.

Trust signals:

- calm black space;
- precise typography;
- restrained effects;
- no fake urgency;
- no confusing navigation;
- clear language;
- real result data;
- Naya as a guide, not a mascot;
- obvious action hierarchy;
- no unexplained metrics.

## CURIOSITY

Use controlled reveals.

Do not explain everything on the first screen.

Give the user a reason to continue:

What is my score?
What creates it?
What does it mean?
What does my shape look like?
What am I naturally good at?
What will Naya recommend?
What is included?

## COMMITMENT

Conversion comes after earned value.

The arc is:

VALUE
→ TRUST
→ RECOGNITION
→ POSSIBILITY
→ PROOF OF DEPTH
→ INVITATION
→ ACTION

This is value-first conversion, not pressure-first conversion.

# 05 — SCENE AND COLOR CHOREOGRAPHY

The page must change atmosphere between major cognitive moments.

Preferred rhythm:

DARK
→ ELECTRIC DARK REVEAL
→ LIGHT EDITORIAL REPORT
→ DARK PATTERN
→ LIGHT / DARK RECOGNITION
→ DARK GUIDED VIDEO
→ LIGHT PREMIUM MEMBERSHIP
→ DARK / PURPLE FINAL INVITATION

This order may be adjusted for composition, but these rules do not change:

- never stack many visually identical sections;
- dark = depth, intelligence, mystery, Naya, Orb, Pattern, major transitions;
- light = reading, clarity, report, reflection;
- purple = transformation and decisive commitment;
- gold = earned achievement, not generic decoration.

Transitions are scene changes, not separators.

Preferred transition devices:

- Orb energy flowing into the next visual;
- soft gradient wash;
- constellation points migrating into new geometry;
- organic curves;
- luminous edge sweep;
- atmospheric field changing hue;
- subtle vertical light seam.

Use one strong transition device per transition. Do not stack effects.

# 27 — PERFORMANCE AND TECHNICAL RULES

The visual system must not become technically reckless.

Prefer CSS/SVG/DOM techniques that are performant and maintainable.

Use GPU-friendly transforms where possible.

Do not create runaway MutationObservers.

Do not bind duplicate listeners.

Do not initialize the same visual component twice.

Do not create a new renderer when the current active owner can be repaired.

Do not use a heavy 3D library merely to make the Orb “look 3D” unless the visual benefit justifies the performance and maintenance cost.

A premium visual that makes mobile unusable is not AAA.
