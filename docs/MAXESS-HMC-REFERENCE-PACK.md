## HMC Quality Translation for MAXESS

MAXESS should inherit the Human Maximus standard rather than invent a disconnected visual language.

Required traits:

- premium;
- human;
- intelligent;
- tactile;
- cinematic;
- confident;
- warm;
- high contrast;
- memorable;
- restrained rather than noisy;
- proprietary rather than library-default.

## Button Standard

Every major button must answer:

WHAT IS THIS?
WHY SHOULD I CARE?
WHAT HAPPENS IF I PRESS IT?

Buttons must be designed as part of a product-wide system, not individually improvised inside each section.

## Icon Standard

Icons are a visual language, not decoration.

They must share:

- stroke/weight logic;
- optical sizing;
- geometry;
- baseline behavior;
- semantic consistency;
- motion behavior.

Micro-icons and bullets are permitted to create rhythm and hierarchy, but never clutter.
