## CUMULATIVE LESSONS

1. **Repository memory is institutional memory.** Material conversation knowledge must be promoted into the correct durable layer.
2. **Current truth beats historical conversation.** Mission State and live repository/runtime evidence control state claims.
3. **Implementation is not proof.** Maintain the evidence ladder: implemented → tested → verified → runtime-proven → production-proven.
4. **The unit of work is the human journey.** Do not optimize isolated screens while the journey remains incomplete.
5. **Failures must improve the system, not just the instance.** Repeated failures trigger root-cause analysis of the guardrail/test/process itself.
6. **A known next action should be executed or delivered as a runnable continuation.** Acknowledgement alone is insufficient.
7. **Unknown must remain unknown until evidence closes it.**
8. **The report is a learning mechanism, not a diary.**
9. **Every successor should inherit the previous Naya's lessons.**
10. **Maximum value per interaction is the optimization target.**

## REPEATED-MISTAKE WATCHLIST

- stale or conflicting current-state briefings
- source/runtime/production parity assumptions
- claiming completion from code presence
- brittle tests that validate implementation shape instead of user-facing contracts
- repairs that are not immediately retested
- competing authority documents
- knowledge remaining only in conversation
- acknowledging an executable next action without delivering it

When a watchlist item recurs, escalate from fixing the instance to fixing the learning mechanism.

## DAILY UPDATE CONTRACT

At each daily cycle:

1. ingest recent project activity;
2. compare with prior reports;
3. identify material changes;
4. identify failures and repeated failures;
5. extract lessons;
6. determine whether each lesson requires a system update;
7. update appropriate durable artifacts;
8. verify the update;
9. update this hub's cumulative synthesis;
10. publish the day's report;
11. define exactly one highest-value next action and exact proof target.
