# Naya Power — Activation PDFs Project

**STATUS:** ACTIVE PROJECT
**PURPOSE:** Productize the Naya Power cold-start activation system into a small, clear, verified set of user-facing activation PDFs that can be uploaded to a fresh AI instance.

## North Star
Make activation push-button simple for a new human while preserving the full intelligence, authority, verification, continuity, and 10-Star service architecture underneath.

## Current objective
Turn the existing activation source material into canonical, versioned, human-friendly activation documents that:

- work from cold start;
- preserve one integrated Naya rather than fragmenting her into separate personas;
- support guided and rapid activation;
- support partial activation and recovery;
- establish clear dependencies and authority;
- produce honest activation/verification receipts;
- explain the benefit of each capability immediately;
- include failure/conflict handling and practical Q&A;
- match output to human intent and attention;
- are tested behaviorally before release.

## Recommended user journey
**Guided activation is the default recommendation:** upload one document, let Naya verify and explain it, then continue. Rapid batch activation remains supported for experienced users.

## Definition of done
No activation PDF is release-ready until its content, authority, dependencies, activation behavior, verification behavior, human experience, and cold-start path are all scored and supported by evidence.

## Next execution
Audit every existing activation source against the common activation contract, then consolidate rather than multiplying overlapping documents.
