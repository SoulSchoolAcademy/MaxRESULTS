## Why it is not 10/10

1. **Green is not yet observed after the latest hardening.**
2. **Retrieval is not yet genuinely semantic/vector at the required level.** Current TF-IDF is useful but is not equivalent to embedding-based semantic retrieval.
3. **Duplicate detection is ahead of duplicate resolution.** The system can identify risk, but high-confidence automatic UPDATE/LINK/SUPERSEDE behavior needs to be completed and tested.
4. **The relationship graph is represented but not yet a first-class derived retrieval structure.**
5. **Daily CIS is not yet fully automatic end-to-end.** Generation exists; verified report→receipt→next-day-state→delivery must be closed.
6. **Higher-order CIS is defined but not fully automated.**
7. **Self-optimization is currently more protocol than closed-loop runtime.**
8. **Cold-start proof is not complete.** A brand-new AI must pass an objective acceptance suite using only repository state.
9. **Human delivery is specified but not fully verified through an actual outbox integration.**
10. **The complete system has not yet been measured against retrieval, latency, reliability, and human-friction thresholds.**

## 10/10 gates

10/10 is granted only when all of these are TRUE:

- CI gate GREEN after the complete implementation;
- all canonical invariants enforced;
- duplicate/entity resolution automated and benchmarked;
- contradiction/supersession automated;
- graph built and used by retrieval;
- semantic/vector retrieval operational with precision/recall/latency benchmarks;
- Daily CIS automatically verified;
- next-day Intelligence State automatically generated and restorable;
- all higher CIS cadences automated;
- health metrics trend over time;
- human-readable receipts and delivery confirmation work;
- cold-start AI acceptance suite passes;
- end-to-end capture→compound→restore test passes;
- no material regression in CI;
- every remaining limitation is intentional, documented, and non-blocking.

**Until these gates pass, the correct status is: HIGHLY HARDENED / NOT YET 10/10.**
