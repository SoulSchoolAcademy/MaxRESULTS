# NayaNET → MAXESS — Part 1

A deliberately complete, static-first first-time experience:

1. **NayaNET entrance** — centered, calm, premium, name-first.
2. **Identity handoff** — personal welcome from Naya, human-readable identity, Smart Link shown explicitly as preview-only.
3. **MAXESS boundary** — a truthful handoff into the next room without inventing an assessment score or pretending the runtime is connected.

## Quality locks

- No Living Sun on the entrance.
- No generic SaaS card grid.
- Black dimensional controls with restrained purple/lime energy.
- No email/password at the first step.
- Keyboard + touch friendly.
- Reduced-motion support.
- Session persistence for the chosen name.
- No fake authentication, fake AI, fake score, or fake public route.
- The Naya image in the package is a user-library visual reference; replace it with the canonical approved binary asset before production release.

## Run

Open `index.html` directly or serve the folder with any static server. No build system is required.
