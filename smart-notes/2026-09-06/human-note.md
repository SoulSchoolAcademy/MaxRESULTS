# Human Note — What Smart Notes Are

The Smart Note is the classification for the complete four-perspective intelligence capture. When I say **make a Smart Note**, I mean: make a Human Note, make a Naya Note, make a Machine Note, and make an Intelligence Activity Feed Note for the same subject and event.

The purpose is continuity. I should never have to hunt through separate Naya Note, Shawn Note, Machine Note, or Activity Feed locations to reconstruct one piece of intelligence. One Smart Note must remain one findable record.

The notes need to be timestamped and chronologically organized so Naya can review everything captured today, yesterday, the day before, or any historical period when producing intelligence reports.

The system also needs a real receipt with evidence links so the event can be reviewed and verified rather than merely assumed to exist.
