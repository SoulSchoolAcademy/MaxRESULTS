# Smart Note — What Smart Notes Are

**Date:** 2026-09-06  
**Canonical definition:** A Smart Note is one intelligence event captured as four coordinated representations of the same subject.

## Human Note
A Smart Note begins with what the human experienced, noticed, learned, decided, questioned, created, won, or needs to remember. This is the human perspective and the source meaning of the event.

## Naya Note
Naya interprets the same event from the AI perspective: what it means, what can be learned, what patterns or implications matter, and what should be carried forward. Naya must never invent evidence or pretend an interpretation exists when it has not been produced.

## Machine Note
The machine representation preserves the event identity, timestamp, source, lifecycle state, privacy boundary, and structured system facts. It is the system-readable record that lets later processes find and reason about the event without changing what actually happened.

## Intelligence Activity Feed Note
The Intelligence Activity Feed is the compact compounding representation of the same event. It announces that new knowledge/intelligence entered the personal intelligence layer so downstream processes such as the Intelligent Hub and Daily Intelligence Report can discover and synthesize it.

## How the four parts work together

**ONE SUBJECT → ONE EVENT → FOUR PERSPECTIVES → ONE VERIFIED INTELLIGENCE RECORD.**

When the user says **"make a Smart Note"**, the system must create all four perspectives, timestamp the event, preserve the source/evidence, verify that all four artifacts exist, and make the completed Smart Note discoverable as one chronological record in the user's Smart Notes collection.

A Smart Note is therefore **not** a Naya Note, a Human Note, a Machine Note, or an Activity Feed Note by itself. Those are four perspectives inside one Smart Note.

## Operational Principle
**CAPTURE → INTERPRET → STRUCTURE → COMPOUND → VERIFY → REMEMBER.**

## Retrieval rule
All Smart Notes belong in one canonical **Smart Notes** collection, ordered newest-first by event timestamp. The collection must support reviewing today's notes, yesterday's notes, earlier days, and the complete historical record without searching through separate Human/Naya/Machine folders.

## Evidence rule
A completed Smart Note must have a real evidence receipt. The receipt records the event ID, verification state, timestamp, and links to the four underlying artifacts whenever those links are available. No receipt means the Smart Note is not complete.
