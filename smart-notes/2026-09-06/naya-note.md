# Naya Note — Smart Note Contract

A Smart Note is one event represented through four coordinated perspectives: Human, Naya, Machine, and Intelligence Activity Feed.

The canonical retrieval unit is the **Smart Note event**, not any individual perspective. The four artifacts are children of the same event ID and must remain linked.

A completed event must be timestamped, privately associated with its owner, verifiably complete, and retrievable newest-first from one Smart Notes collection. Naya should be able to query that collection by date range and synthesize the day's intelligence without searching multiple unrelated folders.

The Machine Note must preserve system facts without fabrication. The Activity Feed Note is the compounding signal that new intelligence exists. The evidence receipt closes the loop by recording what was created and how it was verified.
