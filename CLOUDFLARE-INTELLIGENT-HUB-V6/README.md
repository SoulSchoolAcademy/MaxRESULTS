V6 is a deliberate visual reset from dashboard UI to the NayaNET Elite Interface Standard: fewer words, fewer boxes, stronger visual hierarchy, semantic color, dimensional objects, living light, motion, icons, and high-presence Naya interaction.

MAKE DIGITAL OBJECTS FEEL PHYSICAL.
