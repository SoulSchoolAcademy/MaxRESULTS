# NayaNET Living Sun Intelligent Hub V2

Cloudflare-ready static build of the E02 Intelligent Hub evolution.

## North Star

Naya is the Living Sun. Worlds are orbiting intelligence objects. The Hub is a spatial library and operating environment rather than a conventional dashboard.

## Included

- Front Door with name entry
- Activation transition into the Hub
- Large layered Living Sun centerpiece
- Three spatial orbit bands
- 27 prioritized worlds
- Priority ranks and user-oriented ordering
- Center-stage world detail panels
- Diamond-bullet information presentation
- Local Ask Naya knowledge interaction
- MAXIS and Soul School Academy live destinations
- Responsive/mobile adaptation
- Accessibility labels and keyboard entry for the central Sun
- Cloudflare static headers

## Cloudflare

Deploy this directory as a static site. The application requires no build step and no server runtime.
